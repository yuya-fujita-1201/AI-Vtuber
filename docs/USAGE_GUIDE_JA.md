# AI Vtuber 運用・カスタマイズマニュアル

このマニュアルでは、AI Vtuber「Aiko（Kamee）」の性格調整、感情コントロール、記憶管理、および設定のカスタマイズ方法について解説します。

## 1. 性格と話し方の調整 (Character & Personality)

AIの「魂」となる性格や口調は、以下のファイルを編集することで変更できます。

**対象ファイル**: `src/prompts/system_prompt.ts`

### 編集のポイント
- **AGENT_PERSONALITY**: AIの基本性格、口調、行動ルールを定義しています。
    - 「〜だよ」「〜だね」といった語尾や、好きなもの、嫌いなものを具体的に書くと反映されやすいです。
    - **早口・流暢さ**: 「早口で話すこと」「フィラー（えーっと、など）を使うこと」などを明記すると人間らしくなります。

```typescript
export const AGENT_PERSONALITY = `あなたは...
## キャラクター設定
- 明るくて元気
- 〇〇が好き
...
`;
```

## 2. 感情のコントロール (Emotion Control)

AIは視聴者のコメントを分析し、自動的に感情（NEUTRAL, HAPPY, SAD, ANGRY, EXCITED）を変化させます。
この反応の感度や、感情ごとの声質は設定ファイルで調整可能です。

**対象ファイル**: `src/config/AppConfig.ts` (`emotion` セクション)

### 声の調整 (Voice Map)
感情ごとの「声の高さ（pitch）」「話す速さ（speed）」「抑揚（intonation）」を定義します。

```typescript
    voiceMap: {
      NEUTRAL: { pitch: 0, speed: 1.2, intonation: 1.1 }, // 通常時
      HAPPY: { pitch: 0.05, speed: 1.3, intonation: 1.3 }, // 楽しい時
      // ...
    }
```
- **speed**: 数値を上げると早口になります（推奨: 1.2〜1.4）。
- **pitch**: 数値を上げると声が高く、下げると低くなります。
- **intonation**: 数値を上げると抑揚がつき、表現豊かになります。

### 感情の感度 (Sensitivity)
AIがどれくらい簡単に感情を変えるかを設定します。

- **thresholds**: 各感情に移行するためのしきい値です。数値を下げると、その感情になりやすくなります。
    - `happyMoodMin`: 0.4 (これを超えるとHAPPYになる)
    - `angryMoodMax`: -0.6 (これを下回るとANGRYになる)
- **decay**: 0.6 (感情の冷めやすさ。1に近いほど感情が維持され、0に近いほどすぐリセットされます)

### 特定の感情にさせたい場合
現状、ボタン一つで感情を変える機能はありませんが、以下の方法で誘導できます。
1. **チャットで誘導**: ポジティブな言葉をかければHAPPYに、意地悪なことを言えばANGRYになります。
2. **しきい値の変更**: `happyMoodMin` を極端に低くすれば、常にHAPPYな状態になります。

## 3. 記憶の管理 (Memory Management)

AIは会話の内容を自動的にデータベース（ChromaDB）に保存し、後の会話で活用します。

### 新しいことを覚えさせる (Implanting Memories)
AIに特定の知識や設定を覚えさせるには、主に2つの方法があります。

1. **会話で教える（推奨）**
   - 配信（実行）中に、コメントで話しかけます。
   - 例: 「あなたの好きな食べ物はハンバーグだよ」「私の名前は田中だよ」
   - AIがそれを認識し、重要だと判断すれば自動的に記憶データベースに保存されます。

2. **System Promptに書く（初期知識）**
   - 絶対に忘れてはいけない設定や過去の経歴などは、`src/prompts/system_prompt.ts` に直接書き込むのが確実です。
   - 例: 「あなたは昔、宇宙飛行士でした」とプロンプトに追記する。

### 記憶のリセット
記憶を全て消去してリセットしたい場合は、以下のデータを削除します（実行前にバックアップ推奨）。
- **ChromaDB**: `chroma_data` フォルダ（もしあれば）またはDockerボリューム
- **データベース**: `prisma/dev.db` ファイル

## 4. トラブルシューティング

### Q. 「Unsupported value: temperature...」というエラーが出る
**A. モデルの仕様です。**
`.env` で `gpt-5-mini` や `o1-mini` などの推論特化モデルを使用している場合、`temperature`（創造性パラメータ）は `1` 以外を受け付けないことがあります。
**対応**: 自動補正プログラムを導入済みですので、そのままお使いいただけます。手動設定する場合は `.env` の `PROMPT_REPLY_TEMPERATURE` を `1` にしてください。

### Q. 反応が遅い
**A. LLMの応答速度や音声生成に時間がかかっています。**
- `OPENAI_MODEL` を `gpt-4o-mini` など軽量なモデルにする。
- VOICEVOXのPCスペックへの負荷を確認する。
