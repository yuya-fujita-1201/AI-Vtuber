

# Day 14: Story Mode (Live Storyweaving)

## 📝 Objective
Implement **Live Storyweaving** by creating a `StorytellingService`.
Unlike a fictional game, this feature focuses on **dynamic topic development** inspired by viewer comments. The goal is to make the "talk stream" feel like a coherent narrative journey rather than random Q&A.

## 🎯 Deliverables

1.  **StorytellingService (`src/services/StorytellingService.ts`)**
    *   **Role**: Narrative Director / MC.
    *   **Logic**:
        *   Maintains a `NarrativeArc` (e.g., "Casual Opening", "Deep Dive", "Heated Debate", "Cozy Closing").
        *   Analyzes the "vibe" of the chat to steer the conversation.
        *   Instead of random events, it identifies **"Golden Comments"** (high potential topics) and locks the Agent onto them.
        *   Commands `EmotionEngine` to match the *conversational atmosphere* (e.g., if chat gets excited about a game, lock emotion to EXCITED).

2.  **Story Prompt Logic (`src/core/PromptManager.ts`)**
    *   Add `buildNarrativePrompt()` methods.
    *   Inject "Current Conversation Theme" into the main chat prompt to prevent topic drifting.

3.  **Integration**
    *   Add `StorytellingService` to `Agent`.
    *   Command: `!story topic [theme]` (e.g., `!story topic SpaceTravel` to start a focused discussion).

## 🛠️ Implementation Specs

### Narrative Loop
1.  **Start**: User sets a theme or Agent picks one from trends.
2.  **Progression**: Each comment contributes to the "Topic Depth".
3.  **Twist**: Instead of "intruders", a twist is a **"Controversial Opinion"** or **"Surprising Fact"** generated by the AI to spice up the debate.
4.  **End**: Smoothly transition to a closing summary when the topic is exhausted.

## ✅ Verification
*   [ ] `!story topic` sets the focus.
*   [ ] Agent digs deeper into the topic instead of answering superficially.
*   [ ] Agent generates a "Summary" of the discussion at the end.
